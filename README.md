# Bêta de démonstration — JLisi + Kandel-Moles

Héberger tous les fichiers à la racine du même site HTTP(S) (par exemple GitHub Pages). Ne pas ouvrir directement `index.html` en `file://`, car le navigateur peut bloquer le chargement du fichier JSON de césure.

JLisi est calculé localement. Kandel-Moles utilise les coefficients français de ReadSightPy et ses motifs de césure (approximation typographique des syllabes). Aucun texte saisi n’est transmis à un serveur par l’application.

Attention : GitHub Pages est accessible publiquement même si son adresse est communiquée à un nombre restreint de personnes.
